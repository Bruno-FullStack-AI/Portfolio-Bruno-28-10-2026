## 📁 Estrutura da pasta

```text
.
├── index.html      ← página principal do site
├── assets/         ← imagens usadas pelo site
├── favicon.svg     ← logo/favicon BL premium
├── preview.png     ← imagem de capa deste README
├── robots.txt      ← libera o rastreamento das páginas públicas
├── README.md       ← este arquivo
└── .nojekyll       ← faz o GitHub Pages servir os arquivos como estão
```

## 🚀 Como publicar no GitHub Pages

1. Crie um repositório **público** no GitHub, por exemplo `portfolio`.
2. Clique em **Add file → Upload files**.
3. Envie **o conteúdo desta pasta**: `index.html`, `assets/`, `favicon.svg`, `preview.png`, `README.md`, `robots.txt` e `.nojekyll` se ele aparecer.
4. Clique em **Commit changes**.
5. Vá em **Settings → Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main`, pasta `/(root)`, e clique em **Save**.
7. Aguarde cerca de 1 minuto. O endereço será algo como `https://SEU-USUARIO.github.io/portfolio/`.

## 💻 Rodar localmente

```bash
python -m http.server 8000
```

Depois abra `http://localhost:8000`.
